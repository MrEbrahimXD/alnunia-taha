# alnunia-taha

Al-Nuniyya (al-Kafiya al-Shafiya) of Ibn al-Qayyim — recitation by **Sheikh Taha al-Fahd**.

Audio files are named by the **AlNunia app verse number** (`<verseNumber>.mp3`), aligned to the app's nunia.json (5837-verse edition) via text matching.

- 5788 files (verses 1..5836)
- 49 verses have no Taha recording (Taha's edition has 5789 abyat vs the app's 5837); see `verse_map.json` -> `unmapped_app_verses`.
- Source: Muyassir al-Mutoon app (Taha/noniya1-6 on niszak.com), stitched + remapped.

Served via GitHub Pages: https://mrebrahimxd.github.io/alnunia-taha/<verseNumber>.mp3
